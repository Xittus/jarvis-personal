# Jarvis Personal information pages

Static application information, privacy and usage pages for the owner's personal Google OAuth integration. No Google credentials, authentication callback, mailbox, calendar, forms, analytics or application backend are part of this repository.

Build: `npm run build` (Node built-ins only, no package installation).
Preview: `npm run preview`, bound only to 127.0.0.1:19400.

Proposed host: `jarvis-personal.xittus.workers.dev`, subject to actual Cloudflare publication and Google's domain acceptance. No domain registration is required to prepare these files. Deployment is not yet configured or performed. Worker compatibility date: 2026-11-13.

The personal assistant itself remains in its separate private local installation. Changes to its data handling require updating these notices and obtaining any new Google consent before use.
